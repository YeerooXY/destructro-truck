# Prototype asset provenance

The truck, cosmetic wheels, buildings, wrecks, balloons, and interface are original
placeholder drawings made directly in GDScript for this project. The test yard is
an original authored layout. No artwork, audio, branding, or level data was copied
from the childhood inspiration. No external asset downloads have been included.

The prototype uses Godot's built-in font and engine components. Packaging writes
their copyright/license notices through the engine's own license metadata into
`THIRD-PARTY-NOTICES.txt`. Final art and audio are still pending gameplay feedback.
